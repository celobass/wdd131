Planejamento do Site — VyxelCore

Este documento apresenta o planejamento inicial do site do VyxelCore. O planejamento será utilizado como referência para o desenvolvimento do projeto final e poderá ser ajustado conforme a implementação avance.

1. Nome do Site

VyxelCore — Sistema de Gestão para Impressão 3D

Domínio: vyxelcore.com.br

O VyxelCore é um projeto real em desenvolvimento voltado para a gestão de pequenos negócios e profissionais que trabalham com impressão 3D. O domínio vyxelcore.com.br já foi adquirido e faz parte da identidade do projeto.

O nome VyxelCore foi escolhido para representar uma plataforma que busca centralizar informações e processos relacionados à impressão 3D, como custos, materiais, orçamentos e produção. O desenvolvimento deste site fará parte da evolução do projeto e também será utilizado como projeto acadêmico no curso de Desenvolvimento de Software do BYU-Pathway.

2. Finalidade do Site

O site tem como finalidade apresentar o VyxelCore, um sistema de gestão desenvolvido para auxiliar profissionais e pequenos negócios que trabalham com impressão 3D. O site servirá como uma apresentação do produto, explicando sua proposta, suas principais funcionalidades e os benefícios que pode oferecer para a organização de uma operação de impressão 3D.

O conteúdo abordará recursos como cálculo de custos de impressão, controle de materiais, geração de orçamentos e acompanhamento da produção. O site também apresentará uma área interativa para que o visitante possa realizar uma simulação relacionada aos custos de uma impressão 3D.

O projeto será desenvolvido com HTML, CSS e JavaScript, utilizando um design responsivo que permita uma boa experiência em dispositivos móveis e computadores. A interação com JavaScript permitirá apresentar informações e resultados de forma dinâmica, demonstrando algumas das funcionalidades propostas pelo VyxelCore.

O objetivo principal é informar o visitante sobre a solução e demonstrar como o VyxelCore pode auxiliar na organização e no controle de uma operação de impressão 3D.

3. Cenários

Os cenários representam dúvidas que podem ser apresentadas por visitantes que fazem parte do público-alvo do VyxelCore.

01

Cálculo de custos

“Como posso calcular o custo real de uma peça antes de definir o preço de venda?”

02

Controle de materiais

“Como posso controlar os materiais utilizados nas minhas impressões 3D e acompanhar meus custos?”

03

Orçamento

“Como posso preparar um orçamento para um cliente considerando material, tempo de impressão e outros custos de produção?”

6. Estrutura planejada do site

O projeto final será composto por pelo menos três páginas com navegação e identidade visual comuns.

01

Início

Apresentação do VyxelCore, benefícios, principais funcionalidades, explicação resumida de como funciona e chamada para ação.

02

Funcionalidades

Apresentação detalhada dos recursos de cálculo de custos, materiais, orçamentos e acompanhamento da produção.

03

Orçamento

Formulário e área interativa para uma simulação de custos de impressão 3D, utilizando JavaScript para processar e apresentar os resultados.

8. Considerações para o Projeto Final

O planejamento considera os requisitos gerais da descrição do projeto final. A implementação deverá incluir HTML semântico, CSS responsivo, imagens otimizadas, carregamento lento de imagens quando aplicável, formulário HTML e funcionalidades dinâmicas em JavaScript.

  • Site hospedado no GitHub Pages.
  • Pelo menos três páginas com navegação e tema comuns.
  • Design responsivo para dispositivos móveis e telas maiores.
  • Formulário HTML para a área de orçamento.
  • JavaScript com funções, eventos, manipulação do DOM e condicionais.
  • Uso de objetos, arrays e métodos de array.
  • Uso de template literals para strings de saída geradas pelo JavaScript.
  • Uso de localStorage.
  • Testes de acessibilidade, contraste, desempenho, boas práticas e SEO.
