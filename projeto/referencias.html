Referências do projeto

Esta página apresenta os recursos e as fontes utilizados na elaboração do site demonstrativo VyxelCore, desenvolvido como parte da atividade do curso WDD131.

1. Tipografia

As fontes Montserrat e Roboto são disponibilizadas pelo Google Fonts e utilizadas na identidade visual do projeto.

Google Fonts — catálogo de fontes

2. Imagem ilustrativa

A imagem da impressora 3D utilizada na página inicial foi gerada com auxílio de inteligência artificial para fins ilustrativos e educacionais.

3. Tecnologias utilizadas

  • HTML5 para a estrutura semântica das páginas.
  • CSS3 para o layout, a identidade visual e a responsividade.
  • JavaScript para interatividade, cálculos e manipulação do DOM.
  • LocalStorage para demonstrar o armazenamento de orçamentos no navegador.
  • Git e GitHub para versionamento e publicação do projeto.

4. Documentação técnica

  • MDN Web Docs — HTML
  • MDN Web Docs — CSS
  • MDN Web Docs — JavaScript
  • MDN Web Docs — LocalStorage

O planejamento elaborado na etapa anterior da atividade pode ser consultado no documento abaixo.

Consultar o planejamento do site

6. Observação sobre o simulador

O simulador de orçamento é uma demonstração acadêmica. Os valores apresentados são estimativas e não representam necessariamente todos os custos de uma operação comercial real. Os orçamentos salvos permanecem no armazenamento local do navegador utilizado e não são enviados a um servidor.
